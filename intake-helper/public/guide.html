시험검사의뢰서 → 민원접수 등록 값으로 바꾸고, 사람이 확인한 뒤 접수하는 프로그램

고객지원팀 담당자용

접속 주소 접속 비밀번호 (관리자에게 받으세요)

1들어가기

  1. 브라우저(Chrome·Edge)로 위 주소를 열고 접속 비밀번호를 입력합니다.
  2. 오른쪽 위 "서버 연결 안 됨"을 눌러 본인 사번으로 연결합니다. 접수자는 이 사번으로 기록됩니다.

2의뢰서 불러오기 — 파일 종류에 따라

docx · hwpx · 글자 있는 PDF"파일 선택"에 올리면 바로 읽습니다. 매번 같은 양식으로 오는 의뢰서에 알맞습니다. (.hwp 는 한글에서 hwpx 로, .doc 는 docx 로 다시 저장)
사진 · 스캔 · 손글씨
양식이 제각각인 의뢰서		"변환 방법 보기"를 누릅니다. ① 양식 엑셀 받기 → ② 요청문 복사 → ③ Claude 앱(claude.ai)에 사진, 양식 엑셀, 요청문을 올려 채운 엑셀 받기 → ④ 이 화면의 "엑셀 선택"으로 불러오기
여러 건 한꺼번에"폴더 선택": 폴더 안 파일은 각각 한 건, 하위 폴더는 본지+별첨 한 묶음으로 읽습니다.

3검토 · 확정

  • 왼쪽 원본과 오른쪽 입력값을 나란히 보며 대조합니다.
  • 노란 칸은 읽기가 불확실하거나 순서로만 판단한 값입니다. 원본과 맞으면 "맞음", 다르면 고칩니다.
  • 오류(빨간 표시)가 있으면 확정할 수 없습니다. 업체명, 휴대폰, 의뢰목적, 시료명, 식품유형, 시료량, 시험항목은 꼭 있어야 합니다.
  • 접수 1건은 시료 1건입니다. 시료가 여러 개면 여러 건으로 나뉩니다.

4등록 · 마치기

  • "드라이런"은 서버로 보낼 값을 미리 보는 것입니다. 연구관리시스템에는 저장되지 않습니다. 실제 접수는 KAFRI 민원접수 등록 화면에서 하세요.
  • 접수번호·시료번호는 서버가 부여합니다. 의뢰서에 손으로 쓴 번호는 참고용입니다.
  • 일을 마치면 "엑셀로 저장" 후 "접속 종료"를 누릅니다.
꼭 지켜 주세요
  • 브라우저를 닫거나 새로 고치면 불러온 내용이 사라집니다. 작업 중에는 "엑셀로 저장"을 눌러 두세요.
  • 접속 비밀번호와 사번을 다른 사람과 공유하지 마세요. 접속 기록(사번, 시각)이 서버에 남습니다.
  • Claude 앱 변환은 의뢰서 사진(업체명, 연락처, 사업자번호)이 외부 서비스로 전송됩니다. 기관 정보보안 정책에 따라 사용하세요. docx · hwpx · PDF 변환은 외부로 나가지 않습니다.
  • 이름·번호·주소가 틀리면 청구와 성적서 오류로 이어집니다. 사업자번호가 다르다는 경고가 뜨면 반드시 원본을 확인하세요.
